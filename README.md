# TM-FW-H12
Training month repository for H12

Each week has a directory, in it there is a `Readme.md` file describing the task.

To upload the task, first clone the repo:
1. Copy the url from the green '<> code' menu
2. run `git clone <url>`

Then make a branch and work with it:

3. run `git branch <branch name>`
4. run `git switch <branch name>`

5. add new files to be tracked with `git add week<week nº>/*`
6. commit with `git commit -va`

When you push the first time it'll say there is no remote branch with the name and it will show a message with a command suggestion that contains `--set-upstream`, run that on the first push (all your next pushes can be done with `git push`).
